Политика конфиденциальности Islamic Keyboard

Дата вступления в силу: 22 сентября 2026 года

Настоящая Политика конфиденциальности описывает, как приложение Islamic Keyboard («Приложение») обрабатывает информацию при использовании клавиатуры, библиотеки Корана и других функций Приложения.

Разработчик: Studia ISLAM
Приложение: Islamic Keyboard
Контакт по вопросам конфиденциальности: https://t.me/studiaislam1

1. Основной принцип конфиденциальности

Islamic Keyboard разработан с учётом того, что клавиатура технически может получать доступ к тексту, который пользователь вводит.

Приложение не передаёт вводимый текст, содержимое буфера обмена, пользовательские фразы или другие пользовательские данные на серверы разработчика.

Приложение работает преимущественно локально на устройстве и не содержит встроенной системы удалённой аналитики, рекламных SDK или серверной синхронизации пользовательских данных.

2. Какие данные обрабатывает клавиатура
2.1. Вводимый текст

Когда Islamic Keyboard используется в качестве системной клавиатуры, Android предоставляет клавиатуре доступ к необходимому контексту текущего текстового поля для выполнения функций клавиатуры.

Это может включать текст непосредственно перед курсором, например для:

удаления символов;
автоматического определения регистра;
формирования подсказок;
определения ссылок на аяты;
вставки выбранного содержимого.

Вводимый текст не отправляется разработчику и не передаётся на удалённые серверы приложения.

Приложение не ведёт удалённый журнал набранного текста и не использует вводимый текст для рекламного профилирования.

2.2. Поля паролей

Для полей, которые Android определяет как защищённые поля пароля, приложение ограничивает функции, которые могли бы работать с содержимым поля.

В частности, для таких полей:

история буфера обмена не пополняется содержимым поля;
подсказки слов отключаются;
определение аятов по вводимому контексту отключается;
соответствующие напоминания не показываются.

При этом необходимо учитывать, что безопасность пароля также зависит от приложения, в котором пользователь вводит пароль, и от самой операционной системы Android.

3. Буфер обмена

Islamic Keyboard предоставляет локальную историю буфера обмена.

Если пользователь копирует текст, приложение может прочитать первый текстовый элемент системного буфера обмена и сохранить его локально на устройстве для функции истории буфера.

История ограничена приложением и используется для:

повторной вставки ранее скопированного текста;
закрепления элементов;
организации элементов по папкам.

Данные буфера обмена не отправляются разработчику или на серверы приложения.

История буфера обмена может содержать информацию, которую пользователь самостоятельно скопировал, включая потенциально конфиденциальную информацию. Поэтому пользователю следует удалять такие элементы из истории, если они больше не нужны.

Для защищённых полей пароля приложение не добавляет содержимое такого поля в свою историю буфера обмена.

4. Пользовательские данные, хранящиеся на устройстве

Приложение может хранить локально:

настройки клавиатуры;
выбранные языки;
настройки внешнего вида;
избранные аяты;
недавно открытые аяты;
пользовательские фразы;
историю и закреплённые элементы буфера обмена;
папки буфера обмена;
настройки профилей вставки;
сохранённые пользовательские профили;
недавно использованные эмодзи и связанные настройки;
настройки языка интерфейса;
локальные настройки напоминаний.

Эти данные используются только для предоставления соответствующих функций Приложения и хранятся локально на устройстве.

5. Резервное копирование и экспорт

Приложение позволяет пользователю самостоятельно экспортировать часть пользовательских данных в файл через системный механизм выбора файлов Android.

Экспорт может содержать:

избранные аяты;
недавно открытые аяты;
пользовательские фразы;
папки;
историю буфера обмена;
закреплённые элементы буфера обмена;
профили вставки;
сохранённые профили.

Экспорт выполняется только по действию пользователя.

После создания файла резервной копии его дальнейшее хранение, передача и защита зависят от места, выбранного пользователем. Например, если пользователь сохраняет файл в облачное хранилище или отправляет его другому человеку, обработка этого файла регулируется политикой соответствующего сервиса, а не настоящей Политикой Islamic Keyboard.

Islamic Keyboard самостоятельно не загружает резервные копии на сервер разработчика.

6. Импорт данных

Пользователь может самостоятельно выбрать файл через системный файловый интерфейс Android и импортировать поддерживаемые данные в Приложение.

Приложение не осуществляет автоматический поиск личных файлов пользователя и не загружает выбранные файлы на сервер разработчика.

7. Данные Корана и другие встроенные материалы

Текст Корана, переводы, тафсир, таблицы и другие встроенные материалы, необходимые для работы соответствующих функций, поставляются вместе с Приложением.

Поиск и использование этих материалов выполняются локально.

Для работы библиотеки Корана приложение не отправляет поисковые запросы или выбранные аяты на сервер разработчика.

8. Аналитика

Приложение не содержит встроенных сервисов удалённой аналитики.

В проекте приложения не используются Firebase Analytics, Google Analytics, Crashlytics или аналогичные сторонние сервисы для отправки статистики использования на сервер.

Некоторые локальные технические показатели производительности могут рассчитываться на устройстве для диагностических целей. Они не передаются разработчику автоматически.

9. Отчёты о сбоях

Приложение может локально сохранять информацию о последнем сбое для диагностических целей.

Такой локальный отчёт может содержать:

модель устройства;
производителя устройства;
версию Android;
имя потока;
технический stack trace ошибки.

Последний отчёт о сбое хранится локально на устройстве.

Он не отправляется автоматически разработчику.

Пользователь может самостоятельно открыть диагностический раздел и скопировать отчёт, после чего передать его разработчику по своему выбору. После самостоятельной передачи такого отчёта обработка информации зависит также от выбранного пользователем способа связи.

10. Реклама

Islamic Keyboard не содержит встроенной рекламы и не использует рекламные SDK для показа рекламы.

Приложение не создаёт рекламный профиль пользователя.

11. Передача данных третьим лицам

Разработчик не продаёт пользовательские данные и не передаёт содержимое ввода, локальную историю буфера обмена или пользовательские фразы третьим лицам для рекламы или профилирования.

Приложение содержит ссылки на внешние сервисы, включая YouTube, Instagram и Telegram.

При выборе такой ссылки Android открывает соответствующий внешний сайт или приложение. После перехода пользователь взаимодействует с третьей стороной непосредственно.

Использование этих внешних сервисов регулируется их собственными политиками конфиденциальности. Islamic Keyboard не контролирует обработку данных такими сервисами.

12. Разрешения Android

В текущей версии приложения в AndroidManifest.xml отсутствуют обычные строки uses-permission.

Клавиатура регистрируется как системная служба ввода Android посредством стандартного механизма Input Method Service.

Для передачи встроенных изображений-стикеров другому приложению используется локальный Content Provider с временным разрешением на чтение конкретного изображения, необходимым для функции вставки.

13. Безопасность данных

Поскольку пользовательские данные, описанные выше, хранятся локально, их защита также зависит от механизмов безопасности Android и физической безопасности устройства пользователя.

Приложение не создаёт собственный удалённый сервер для хранения пользовательских данных.

Пользователю рекомендуется:

использовать блокировку экрана устройства;
не передавать другим людям файлы резервных копий, содержащие личную информацию;
удалять конфиденциальные элементы из истории буфера обмена после использования;
не импортировать резервные копии из ненадёжных источников.
14. Срок хранения данных

Локальные пользовательские данные хранятся на устройстве до тех пор, пока они нужны пользователю или пока пользователь не удалит их средствами Приложения или Android.

Данные, хранящиеся в локальном хранилище приложения, не имеют отдельного срока хранения на сервере, поскольку приложение не отправляет их на сервер разработчика.

Локальный отчёт о последнем сбое заменяется новым отчётом при следующем сохранении ошибки либо удаляется пользователем через диагностический раздел.

15. Удаление данных

Islamic Keyboard не требует создания пользовательской учётной записи.

Поэтому отдельной процедуры удаления аккаунта нет.

Пользователь может удалить локальные данные приложения стандартными средствами Android, например:

открыть настройки Android;
открыть информацию о приложении Islamic Keyboard;
выбрать хранилище/данные приложения;
удалить данные приложения.

Удаление приложения также удаляет его локальное хранилище в соответствии с механизмами Android.

Пользователь также может самостоятельно удалять отдельные элементы истории буфера, пользовательские фразы, избранное и другие поддерживаемые локальные данные внутри приложения.

Файлы резервных копий, экспортированные пользователем за пределы приложения, не удаляются автоматически при удалении Islamic Keyboard. Пользователь должен удалить такие файлы самостоятельно из места, где он их сохранил.

16. Дети

Islamic Keyboard не требует создания аккаунта и не предназначен для сбора персональной информации о детях.

Приложение не осуществляет целенаправленный сбор персональных данных детей.

Если приложение будет в будущем изменено таким образом, что характер обработки данных изменится, настоящая Политика будет обновлена до публикации соответствующих изменений.

17. Изменения настоящей Политики

Мы можем обновлять настоящую Политику конфиденциальности при изменении функций приложения, способов обработки данных или требований законодательства.

Обновлённая версия будет опубликована по тому же публичному адресу Политики конфиденциальности.

Дата последнего обновления указывается в начале документа.
